# SleepStageClassification_EEG
# EEG Signal Processing and Sleep Stage Analysis

This project explores the computational analysis of electroencephalography (EEG) signals for sleep-stage characterisation. Using frequency-domain analysis and signal decomposition, the project investigates the distinctive spectral properties of brain activity across different sleep stages, with a particular focus on identifying characteristic patterns associated with alpha, beta, theta, and delta brainwaves.
 
The implementation involves applying **Fourier Transform (FT)** to individual EEG channels, examining their frequency spectra, and developing a signal decomposition function to separate raw EEG recordings into their constituent frequency bands. These representations are subsequently analysed to extract distinguishing spectral features, investigate variations in brainwave activity across sleep stages, and interpret previously unclassified EEG recordings based on their frequency-domain characteristics.
 
The project demonstrates an application of computational signal processing to physiological data analysis, encompassing frequency-domain feature extraction, multichannel signal analysis, visualisation, and pattern-based classification. It also provides a foundation for exploring broader connections between signal representation, feature extraction, and automated classification techniques applicable to biomedical signal analysis and other data-intensive research domains.
